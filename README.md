# 旅行プランナー

自分用の旅行プラン管理アプリ。ビルド不要の単一HTMLファイルです。

## 使い方

[index.html](index.html) をブラウザで直接開くだけで使えます。

- 📅 スケジュール: 日程ごとの予定(時刻・場所・メモ)を管理
- 💰 予算: 予算上限と支出(カテゴリ・金額・メモ)を管理
- 📍 候補地: 行きたい場所のリンク・メモ・検討状況を管理

データはブラウザの localStorage に自動保存されます。他の端末へ移す場合や
バックアップを取りたい場合は、画面上部の「書き出し (JSON)」でファイルに保存し、
「読み込み」で復元してください。
